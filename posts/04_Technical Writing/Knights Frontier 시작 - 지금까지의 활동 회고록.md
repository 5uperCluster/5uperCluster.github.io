# Knights Frontier 시작 - 지금까지의 활동 회고록

HSpace Knights Frontier 활동을 시작하며, 지금까지 내가 해온 활동들을 정리하고 회고록을 작성하게 되었다. 중학생 때부터 보안에 대한 막연한 동경과 관심은 있었지만, 막상 제대로 된 공부를 하지는 못해 많은 보안 관련 활동들을 많이 하진 못했던 것 같다. 이번 기회에 내가 그동안 컴퓨터 공학과 정보 보안 분야에서 어떤 활동들을 해왔는지 하나 하나 정리해보고, 이를 바탕으로 앞으로의 새로운 활동을 이어가도록 하겠다.

---

### **지금까지 해온 것들**

  처음 프로그래밍을 제대로 공부하기 시작한 것은 중학교 1학년 때였다. 학교 동아리 시간에 C언어를 처음 배웠다. 이후 중학교 3학년까지는 Python을 학습하고, C언어도 조금 더 깊게 학습했다. 알고리즘을 깊게 공부한 것도, 복잡한 프로그램을 만들어 본 것도 아니지만, 편하게 사용할 수 있는 프로그래밍 언어 2개를 만들었다는 것에 의미를 두었다. 이 무렵, 주변의 권유를 받아 정보 올림피아드, 소프트웨어 사고력 올림피아드에 참가해 장려상을 수상했다. (알고리즘 공부 하나도 안 한 것 치곤 잘한 것 같다.) 높은 성적은 아니었지만, 컴퓨터 분야로 결정한 진로를 더욱 공고히 하는 역할을 해준 것 같다.

  고등학교에 진학한 이후로는, 대학 입시를 준비하느라 큰 활동을 거의 하지 못했다. 생활기록부에 기재할 간단한 탐구 활동들을 진행했다. 대칭키, 공개키 암호의 기본적인 개념, AES, Diffie-Hellman, 블록체인, 양자 컴퓨터의 개념을 탐구하고, 간단한 프로그래밍을 통해 직접 구현해보기도 하였다. 이때 전에 학습했던 Python이 도움이 꽤 되었던 것 같다. 고등학교 때의 활동들은 대부분 개념과 그 개념의 활용 방법을 단순히 조사한 것에 그치는 경우가 많았지만, 이를 통해 보안에 대한 흥미가 더 생기고, 사람들 앞에서 발표하는 것에 많이 익숙해지는 효과를 얻을 수 있었다. (매 탐구마다 발표를 반강제로 하게 됐었다.)

  대학에 입학한 후, 본격적으로 보안 공부를 하기 시작했다. 학교에서는 1학년 수업부터 바로 보안, 해킹을 가르치지 않기 때문에, 동아리에 가입해서 보안을 공부하기로 결심했다. 과 정보보호 동아리 CyKor와  SSH에 가입하여 활동을 시작했다. CyKor에서는 교육생으로 참여하여 암호학, Pwnable, Reversing, Web Hacking을 처음 접하게 되었다. 기본적인 개념과 도구 사용법을 강의를 통해 학습하고, 주어진 과제를 해결했다. SSH에서는 선배의 멘토링을 받으며 리눅스(WSL) 사용법, Git과 Github 사용법, Docker 기초를 배웠다. 많은 것들을 한 것 같지만, 사실 모든 것들을 완벽히 소화해내진 못했다. 조금의 핑계를 대자면 새로운 학교 생활에 적응하고, 학교 수업을 따라가고, 알바도 틈틈이 하며 보안 공부까지 완벽히 하기는 무리가 있었던 것 같다. 그래서 CyKor에서 진행했던 Pwnable, Web Hacking은 잘 해내지 못했으며, 나머지에 대해서도 기초적인 수준에서 아직 멈춰있다.

### **앞으로의 계획**

  Knights Frontier에 참가하며 다시 새롭게 시작하는 마음으로, 지금까지 미뤄왔던 보안 공부를 제대로 해보려고 한다. 기존에 완벽히 소화해내지 못했던 Pwnable과 Web Hacking을 포함하여 다양한 보안 분야 전반을 학습하고, 이후 CTF에 출전해 입상하는 것이 목표이다. CTF 이외에도 알고리즘도 공부하여 기존에 부족하다고 느꼈던 프로그래밍 능력도 발전시킬 것이다. 개발 능력과 여러 보안 분야에 대한 지식을 바탕으로, 나와 잘 맞는 특정한 분야를 찾아서, 그 분야의 최고가 될 수 있도록 할 것이다. 또한, 인공지능이 빠른 속도로 발전하는 시대에 맞추어, 인공지능에 대한 공부, 인공지능과 보안에 대한 공부도 해보고 싶다.

### 정리

- 지금까지 한 것: 프로그래밍 공부, 보안 개념 학습, 리눅스, 깃, 얕은 수준의 암호학, Pwnable, Reversing, Web Hacking
- 앞으로 할 것: 해킹, 보안에 대한 더욱 깊은 공부, CTF 참가, 알고리즘 공부, 인공지능 공부

이 모든 것들을 다 이루고, 더 이루어 가기를 바란다.
